# Hardcore Crystal roadmap

Phase 0  Foundations: build matches ROM, trainer death, key items, mapper and bank scheme, save expansion.
Phase 1  Battle engine: move category split, Special split, type chart, fixed evolutions, base stats.
Phase 2  Roster: 83 three-stage lines (249 species), purge legendaries and single stages, sprites, cries, dex text.
Phase 3  World: design doc, map tools, start area, four sections (~800 battles), final area (~200 battles).
Phase 4  Story: kill milestones (200 tidal wave, 800 crater and portal), thief, ending, dialogue.
Phase 5  Audio and polish: silent ambient loops, title, SFX, comedy pass.
Phase 6  Balance, tests, milestone patches, final ROM only after the user sends the last change list.

Open questions: evolution level reading, battle music, breeding, trading, day and night.
